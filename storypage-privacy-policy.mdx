StoryPage is a browser extension from Next Step Conrad that lets a user select or capture webpage content and transform it into an editable illustrated story, comic, coloring page, or educational resource.

## Information StoryPage handles

StoryPage handles information only when needed for a feature the user chooses:

- Website content, page titles, page URLs, selected text, and visible transcripts when the user chooses to capture a source page.
- A visible video frame or visible-tab image when the user requests a feature that uses visual source context and the page permits capture.
- Story text, prompts, settings, generated artwork, and exported documents.
- API credentials the user supplies for an AI provider.
- A StoryPage Pro license or subscription activation key and entitlement status.
- Subscription identifiers, monthly credit usage, request identifiers, and cost reservations used to enforce included AI allowances.
- An email address associated with a Stripe purchase, when supplied during Checkout, for purchase fulfillment and license support.

## How information is used

Captured content and user instructions are used only to provide StoryPage’s user-facing creation, editing, continuity, storage, and export features. When a user starts an AI operation, StoryPage sends the content required for that operation directly to the AI provider selected by the user when using their own keys.

When the user chooses included subscription credits, required text, prompts, and reference images pass through the Next Step Conrad service hosted on Cloudflare to OpenAI. The business OpenAI key stays encrypted on the server and is never sent to the extension. StoryPage does not persist these prompts or images in its server-side usage ledger. The provider’s own terms and privacy policy apply to that processing.

StoryPage sends checkout and license requests to the Next Step Conrad StoryPage service. Payment details are collected and processed on Stripe-hosted pages; StoryPage does not receive or store complete payment-card information.

## Storage and retention

Provider credentials, settings, entitlement status, and generated projects are stored locally in the user’s Chrome profile. Books and artwork are stored in local browser storage until the user deletes them or removes the extension. Information sent to an AI provider or Stripe is retained according to that provider’s policies. License records are retained by Next Step Conrad for as long as needed to provide, restore, secure, and support the purchased license. Subscription activation records and usage accounting are retained as needed for billing, allowance enforcement, fraud prevention, and support.

## Sharing and sale of data

Next Step Conrad does not sell user data. Information is shared only with the service selected or required to perform a requested feature, including the user’s selected AI provider, Stripe for checkout, and infrastructure providers needed to operate license verification, subscription billing, and included AI processing. StoryPage does not use browsing activity for advertising, credit decisions, or unrelated profiling.

## Limited use

StoryPage’s use and transfer of information received from Google APIs complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Data is used only to provide or improve the extension’s prominent user-facing features.

## Security

Network requests use HTTPS. Provider credentials are restricted to trusted extension contexts and are not included in exported books. Users should protect their provider and license keys and revoke a provider key if they believe it has been exposed.

## User choices

Users choose when to capture a page and when to send content to an AI provider. They can clear provider credentials in Settings, delete locally stored books, export backups, or uninstall StoryPage to remove extension-managed local data. Subscribers can select their own API keys or included credits in the Pro page, and open Manage billing / cancel to cancel renewal. Users can contact Next Step Conrad to request support for purchase, subscription, usage, and license records.
